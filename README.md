# عالم يَمان

هدية رقمية لحفظ ذكريات يمان: صور وفيديو وتسجيلات، ورسائل تُفتح في يوم تختاره الأم، ورحلة نمو بالأشهر والسنوات.

## التشغيل

```bash
npm install
npm run dev        # تطوير على http://localhost:5180
npm run build      # بناء النسخة النهائية في dist/
npm run preview    # معاينة النسخة المبنية
npm run typecheck  # فحص الأنواع
```

النشر موقع ثابت: يكفي رفع مجلد `dist/` على أي استضافة ثابتة (GitHub Pages أو Cloudflare Pages أو Netlify).

## البيانات (مهم)

- كل شيء محفوظ **في متصفح المستخدم فقط** (IndexedDB). لا خادم ولا مزامنة ولا نسخ احتياطي تلقائي.
- من القائمة: **تصدير** ملف JSON يحوي كل الذكريات والرسائل والصور، و**استرجاع** منه.
- طبقة التخزين مفصولة خلف الواجهة `MemoryRepo` في `src/types.ts`، والتنفيذ الحالي في `src/data/idb.ts`. نسخة سحابية لاحقة تستبدل هذا الملف دون لمس الشاشات.
- قفل الرسائل المؤجلة في هذه النسخة **على الجهاز فقط** (حسب ساعته). الحماية الحقيقية تحتاج خادمًا يتحقق من موعد الفتح قبل تسليم المحتوى.

## الخلفيات

أربع صور ثابتة في `src/assets/bg/`، واحدة لكل قسم. هي خلفية فقط، وكل زر ونص وصورة فوقها عنصر حقيقي. تُضبط شفافية الطبقة العاجية فوقها لكل قسم في `src/components/Shell.tsx`.
